# TiTi Strategic Advisory Ledger

برای آخرین گزارش فارسی TiTi همیشه این فایل را بخوانید:

`TITI_LATEST_FA.md`

آرشیو نسخه‌های قبلی در `archive/` نگه‌داری می‌شود و `INDEX.md` فهرست گزارش‌ها و پروتکل به‌روزرسانی را توضیح می‌دهد.

این پوشه `NON-CANONICAL / ADVISORY ONLY` است و هیچ Task، PASS، Run authority، Integration، Promotion، Runtime یا Production authority ایجاد نمی‌کند.
