# Review Scope

Public review should focus on architecture-level counterexamples before any schema is written.

Priority review areas:

- Principal vs persistent Manager Agent distinction
- Accountability/remediation completeness
- Multidimensional authority and aggregate-risk composition
- Commitment binding/apparent promise semantics
- Objective refinement and metric gaming
- No-sixth-plane World 8 binding
- Fenced canonical continuity and migration partition failures
- Shared-engine isolation and cascade failures
- Evidence independence/selection/counterevidence
- Succession dispute and no-auto-coronation

Reviewers should identify concrete falsifiers rather than broad stylistic preferences.
