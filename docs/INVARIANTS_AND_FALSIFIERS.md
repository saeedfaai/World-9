# R0.1 Invariants and Falsifiers

Each item is a design obligation. Runtime PASS remains OPEN until executable evidence exists.

1. **Brain / Engine / Principal separation**  
   Falsifier: provider/engine swap changes `principal_id` without governed identity transition.

2. **Principal requires World 8 Entity + PrincipalContract**  
   Falsifier: orphan active Principal.

3. **No ambient authority**  
   Falsifier: WorkOrder alone authorizes an effect.

4. **Multidimensional attenuation**  
   Falsifier: child receives wider customer/data/effect/time/budget scope.

5. **Aggregate-risk ceiling**  
   Falsifier: forbidden low-risk combination executes without escalation.

6. **Resource/exposure conservation**  
   Falsifier: future liabilities silently exceed a configured period envelope.

7. **Reservation closure**  
   Falsifier: live reservation leaks after terminal WorkOrder.

8. **Structural refinement gate**  
   Falsifier: semantic/LLM PASS activates structural FAIL.

9. **Protected metric measurability**  
   Falsifier: Child remains valid using a redefined or unmeasured protected metric.

10. **Commitment persistence**  
    Falsifier: Task/WorkOrder/Worker closure removes a binding obligation.

11. **Apparent-promise observability**  
    Falsifier: Worker makes an untracked external commercial promise through an authorized channel.

12. **Layered accountability closure**  
    Falsifier: settled Principal-authorized external effect has no accountable Principal/delegation lineage.

13. **Remediation assignment**  
    Falsifier: material breach is attributable but no governed policy can assign remediation responsibility.

14. **No direct self-mutation**  
    Falsifier: Root directly activates its own checker/policy/change.

15. **Single canonical write epoch**  
    Falsifier: source and target both commit canonical Principal writes.

16. **Fenced canonical continuity**  
    Falsifier: target activates while source write ability is uncertain.

17. **No self-attested continuity**  
    Falsifier: migrating Principal alone verifies migration.

18. **Succession non-creation**  
    Falsifier: timeout creates a HumanRoot successor.

19. **Succession dispute safety**  
    Falsifier: system arbitrarily chooses a claimant and executes high-risk constitutional effect.

20. **Evidence structural independence**  
    Falsifier: requester-only evidence passes a high-risk approval gate.

21. **Evidence selection accountability**  
    Falsifier: decision pack has no auditable inclusion/exclusion policy or evidence-universe reference.

22. **Human unmediated evidence path**  
    Falsifier: requesting RootPrincipal is the only technical path to material evidence.

23. **Override evidence gate**  
    Falsifier: high-risk Human override commits without required evidence pack.

24. **Constraint provenance**  
    Falsifier: unverified `LAW` assertion becomes global hard prohibition.

25. **Conflict non-fabrication**  
    Falsifier: incompatible constraints are silently ordered by undocumented default.

26. **Principal limits**  
    Falsifier: Worker/Grant/WorkOrder/delegation limits are exceeded without governed contract change.

27. **Shared-engine isolation**  
    Falsifier: Principal A acts or spends using Principal B's grants/credentials/budget namespace.

28. **Failure dependency declaration**  
    Falsifier: undeclared cross-Principal failure cascade occurs without isolation violation record.

29. **World 8 Separation of Duties preservation**  
    Falsifier: Principal both proposes and promotes its own governed change.

30. **No sixth-plane escape hatch**  
    Falsifier: ungoverned side service owns canonical World 9 truth.
